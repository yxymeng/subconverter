# 规则缓存按有效期复用，更新失败显式选择旧版

用户主要使用 Windows 上的长期运行服务，转换 Ruleset/Clash.ini 供自己的本机和局域网设备使用；首次加载几十份规则较慢，但优先要求应更新的规则完成更新后再生成结果。规则缓存有效期内允许复用，过期或主动强刷时等待必需更新完成；必需规则集更新失败时明确报错，并保留上一次成功版本供用户手动选择。

该选择牺牲了过期缓存时立即响应的速度，避免自动使用旧版或静默遗漏规则导致转换结果与用户预期不一致。未来优化应通过诊断、受控并发、请求合并与处理结果缓存缩短等待，不将默认行为改成先返回旧规则再后台更新。此 ADR 记录用户确认的取舍，本轮已经实现并通过完整应用的模拟源回归。旧版选择按每个规则文件最后一次成功下载的缓存读取，并非历史转换整体快照；缺少缓存时依然报错。
